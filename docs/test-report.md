測試中發現並已修正的問題：

1. Newton 法在價格發散時相對殘差變小而誤判收斂 → 改為同時檢查起點量級（`solver.js`）。
2. 非線性項在測試點量級極小時被判為線性，代回核對失敗 → 改為退回 Newton 法，找不到則回報「找不到解」。
3. CSS `display` 覆蓋 `hidden` 屬性，造成空白通知框 → 加入 `[hidden]{display:none!important}`。
4. 座標軸刻度顯示 `5.00e+3` → 改為一般數字寫法。
