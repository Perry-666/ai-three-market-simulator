## 1. 目標與範圍

建立公開可用的繁體中文「AI 三市場供需模擬器」，作為台積電與其他研究使用者可調整的模型介面：替換輸入資料、修改因子、係數、父層換算關係與供需方程式，觀察它們如何經三市場影響**核心產出——年度均衡算力 Q_C\*（PFLOP-hour／年）**，並提供單因素敏感度排名。

### 1.1 範圍內
1. 2027 單期比較靜態；期初存量給定；使用實際物理與貨幣單位。
2. 四個 Player、三個市場、六條供需線與跨市場傳導（Notion 04）。
3. 兩層因素：41 個 Level 1（直接進入供需式）、61 個 Level 2（先更新父層）。
4. 兩種輸入方式：直接設定 Level 1、由 Level 2 換算（父層被選為衍生時鎖定直接輸入）。
5. 三市場聯立求解（預設）與單市場觀察（條件均衡）。
6. 單因素端點敏感度：Level 1／Level 2 分開排名、龍捲風圖、區間掃描。
7. 情境保存、JSON 匯出匯入、CSV 匯出、本機儲存。
8. 公開 HTTPS 靜態網站，計算全在瀏覽器。

### 1.2 範圍外（本版不做）
- 隨機抽樣、分布、Sobol、bootstrap、多因素低中高組合。
- 容量／預算上限、min／max 截斷、非負截斷。
- 年度情境路徑與跨期方程（Notion 06 §9，列為後續工作 R17–R20）。
- 台積電 CSV 匯入與公司資料代入面板（Notion 06 §2.1，後續工作）。

## 2. 模型（唯一數值來源：Notion 04 ＋ Appendix）

### 2.1 六條供需線
```
Q_H^S = H_s + b_H·P_H
Q_H^D = H_d − d_H·P_H + k_HC·P_C            （k_HC = d_H·m，m = 20,000）
Q_C^S = C_s + b_C·P_C − k_CH·P_H            （k_CH = d_H·h_new ≈ 40,000/3）
Q_C^D = C_d − d_C·P_C + a·Q_A^D             （a·Q_A 為推論算力）
Q_A^S = A_s + b_A·P_A − k_AC·a·P_C          （k_AC = b_A，毛利 P_A − a·P_C）
Q_A^D = Q_E^D + Q_U^D + Q_G^D               （d_E + d_U + d_G = 2×10¹⁰）
```
非價格項 H_s、H_d、C_s、C_d、A_s、E_d、U_d、G_d 依 Notion 04 的 Δ 形式實作，係數具名可編輯。

### 2.2 基準均衡（驗收用）
P_H＝100,000 美元／有效 PFLOPS、P_C＝5 美元／PFLOP-hour、P_A＝1 美元／百萬 token；
Q_H＝1,000,000 有效 PFLOPS／年、**Q_C＝8,000,000,000 PFLOP-hour／年**、Q_A＝40,000,000,000 百萬 token／年；
企業／個人／政府＝240／80／80 億百萬 token／年；推論與其他算力各 40 億 PFLOP-hour。

### 2.3 父層換算（Level 2 → Level 1）
22 條換算式＋6 個中間量（J_F、J_P、C_F、C_P、G_F、G_P），依 Notion 03／Appendix §5.1 與試算表「Level2換算」。台積電鏈：CapEx 與量產時間 → 產能 → 合格產出 G_F／G_P → N（固定反應彈性 0.25／0.35／0.2／0.2）。

## 3. 功能需求

| 編號 | 需求 |
|---|---|
| FR-1 | **因素面板**：41 個 Level 1 依四個 Player × 五大項分組，顯示符號、單位、資料可得性、來源性質、下限／基準／上限；滑桿與數字框同步；r、e、M、K_C 等跨市場共用一份狀態。 |
| FR-2 | **子變數面板**：61 個 Level 2 依父層分組；修改子項先更新其全部父層（自動切換為換算模式並提示），再求均衡；不把換算值截回父層區間。 |
| FR-3 | **輸入方式**：每個有子項的 Level 1 可切換「直接設定」或「由子項換算」；換算模式鎖定直接輸入並顯示換算結果。 |
| FR-4 | **係數面板**：價格斜率、跨市場係數、各式非價格項係數與截距，標示「推導」或「設定」，附單位與用途，可重設。 |
| FR-5 | **方程式編輯器**：六條供需式、非價格項與父層換算式皆可編輯；受限數學解析器（不使用 eval），公式預覽與引擎共用同一語法樹；未知符號、除以零、循環依賴、非有限值指出位置。 |
| FR-6 | **求解**：預設三市場聯立（線性時直接線性代數求解並代回核對；非線性改數值求解）；單市場觀察固定其他價格並標示條件均衡。相對容差 10⁻⁸、絕對容差 10⁻⁶；區分無解／無唯一解／病態／找不到解／不適用。 |
| FR-7 | **均衡圖**：三張供需圖，基準虛線、新情境實線，標出均衡點與絕對／百分比變化；各圖使用該情境的其他市場均衡價格；可只顯示非負區域但不改寫運算。 |
| FR-8 | **敏感度**：保存基準快照求 Q₀；每個因素只改到下限或上限重新求均衡；δ＝100×(Q−Q₀)/Q₀，分數 S＝max(|δ下|,|δ上|)；Level 1／Level 2 分開排名，容差內並列；龍捲風圖以 0% 為基準；可點選因素做 21 點區間掃描並提示非單調。 |
| FR-9 | **保存與匯出**：JSON 含方法識別 `oat_baseline_pct_max_abs`、模型版本、因素與上下限、單位與來源、父層決定式、輸入模式、係數、公式、容差、結果與敏感度；CSV 匯出因素與敏感度（含單位與百分比）；本機儲存自動恢復。 |
| FR-10 | **安全與驗證**：下限≤基準≤上限檢查；h＞0、u≥1、比例 0–100；利率與預期可為負；負價格／負數量／負分群需求標為不適用，不用 max(0,x) 改寫。 |

## 5. 已知限制（介面需揭露）
1. 2027 單期研究情境；除少數公開參照值外，區間與係數都是研究者假設，尚未由資料估計。
2. 敏感度分數同時反映區間寬度與模型反應係數，不是因果效果、機率或變異數占比，不同因素不相加。
3. 線性近似；資源條件只移動曲線，沒有容量或預算上限。
4. 台積電渠道為給定生產情境的影響分析，不輸出最適 CapEx，也不反推擴產缺口。
5. 單位以宣告與顯示為準；Δ 形式的基準常數使自動量綱檢查多回報「未驗證」，介面照實標示，不冒稱已檢查。
