# 規格（Spec）：AI 三市場供需模擬器

- 規格編號：001-three-market-simulator
- 狀態：已核定，進入設計
- 來源需求：Notion「05｜Codex 交接：三市場互動供需模擬器」
- 依據資料：Notion「03｜Main Factor 量化：簡化版」（變數表）、「04｜由量化因素建立三市場供需曲線」（公式與符號）
- 開發方式：SDD（Spec-Driven Development）。本文件先定義「做什麼、怎樣算完成」；`design.md` 定義「怎麼做」；`tasks.md` 把設計拆成可追溯到本規格的任務。

---

## 1. 目標與範圍

建立繁體中文「AI 三市場供需模擬器」，讓使用者調整外生因素、影響係數與方程式，系統即時求出硬體（H）、算力（C）、AI 服務（A）三個市場的均衡價格與數量，並在供需圖上比較「基準」與「新情境」。

### 1.1 範圍內

1. 比較靜態（comparative statics）；初始存量給定。
2. 沿用實際單位（美元、%、MW、月、PFLOPS、PFLOP-hour、百萬 token…），不引入「基準＝100」或自訂算力單位。
3. 三市場聯立均衡（預設模式）與單市場觀察（選用模式）。
4. 因素面板、係數面板、方程式編輯器、情境比較（儲存基準／重設／複製／JSON 匯出匯入）、教學提示。
5. 瀏覽器端完成全部計算；情境存在瀏覽器本機儲存。
6. 可公開透過 HTTPS 使用的靜態網站。

### 1.2 範圍外（本版明確不做）

- 十年時間模擬、部署與退役的時間方程式；Q_H 不自動加入 K_C。
- 容量上限、預算上限、min／max 截斷、非負截斷。
- 投入產出數量一致性（Q_C 與 a×Q_A＋訓練耗用）——保留為已知限制並在結果旁說明。
- 帳號、共用資料庫、多人即時編輯、後端服務。

## 2. 名詞與符號

| 名詞 | 定義 |
|---|---|
| 因素（factor） | 第 03 頁列出的外生變數，如 r、e、M、a。跨市場共用者只有一份狀態。 |
| 係數（coefficient） | 截距 A、價格反應 b／d、因素影響 k。依第 04 頁：b、d 為正，k 非負。 |
| 未知價格 | P_H、P_C、P_A。聯立模式中是輸出，不是滑桿。 |
| 衍生式 | 由其他符號定義的中間量，如 `c_elec = e * epsilon * u`、`Q_A_D = Q_E_D + Q_U_D + Q_G_D`。 |
| 基準（baseline） | 使用者選定、用來比較的情境。 |
| 新情境（current） | 使用者目前正在調整的情境。 |
| 有效均衡 | 通過殘差檢查且價格、市場數量、分群需求皆非負的解。 |
| 來源標記 | `observed`（來源觀測值）、`assumption`（示範假設）、`calibrated`（示範校準反推）、`user`（使用者輸入）。第 03 頁「待填」項目另記 `pending` 狀態，不轉成 0、不稱為實測。 |

命名：`epsilon`＝ε；`A_H_S` 讀作 A<sub>H</sub><sup>S</sup>；`Q_H_S` 讀作 Q<sub>H</sub><sup>S</sup>。E／U／G＝企業／消費者／政府；`s_E`、`s_G` 是任務成功率；使用量占比記 `share_E`、`share_U`、`share_G`。

## 3. 預設模型（來源：05 §4，須逐字轉入引擎）

```
c_elec = e * epsilon * u

Q_H_S = A_H_S + b_H*P_H - k_Hc*c/h + k_Hy*y - k_Hr_S*r + k_HN*N
Q_H_D = A_H_D - d_H*P_H + k_HC*P_C - k_Hr_D*r - k_He*e - k_HL*L + k_HM*M

Q_C_S = A_C_S + b_C*P_C - k_CH*P_H - k_Cr_S*r - k_Ce*c_elec - k_CB*B + k_CM*M + k_CK*K_C
Q_C_D = A_C_D - d_C*P_C + k_CA*P_A - k_Cr_D*r + k_Ca*a + k_CF*F

Q_A_S = A_A_S + b_A*P_A - k_AC*a*P_C - k_AD*p_D - k_Aw*w - k_Ar_S*r

Q_E_D = A_E - d_E*P_A + k_Ev*v_E - k_EI*I_E + k_Es*s_E - k_Er*r + k_EW*W_E
Q_G_D = A_G - d_G*P_A + k_Gv*v_G - k_GI*I_G + k_Gs*s_G - k_Gr*r + k_GW*W_G
Q_U_D = A_U - d_U*P_A
Q_A_D = Q_E_D + Q_U_D + Q_G_D
```

聯立模式求 P_H、P_C、P_A 使 `Q_i_S − Q_i_D = 0`（i＝H、C、A），再代回求 Q_H、Q_C、Q_A。

## 4. 使用者故事

- **US1 調整因素看均衡**：身為學習者，我拖動利率 r，三個市場同時重新求解，並在三張圖上看到基準與新均衡的差異。
- **US2 調整係數**：身為研究者，我修改 k_HN 等係數觀察移線幅度，並可一鍵重設係數。
- **US3 修改方程式**：身為研究者，我修改某條供需式，系統解析、重算、畫圖；打錯字時告訴我錯在哪，不冒充新均衡。
- **US4 單市場觀察**：身為學習者，我固定其他兩個價格，只看某市場的條件交點。
- **US5 保存與分享情境**：我把情境存成基準、複製、匯出 JSON 傳給同事，同事匯入後得到相同公式、輸入與結果。
- **US6 公開使用**：任何人拿到網址即可在一般瀏覽器使用，不需安裝、登入。

## 5. 功能需求

### FR-1 因素面板（R02、R08、R09）
1. 列出第 03 頁每個因素的中文名稱、符號、單位、目前數值、來源標記（觀測值附出處；待填者顯示「來源：待填，目前為示範假設值」）。
2. 每個因素有滑桿與可直接輸入的數字框，兩者同步；具 `<label>` 與單位，可鍵盤操作。
3. r、e、M、a 跨市場共用，只有一份狀態；面板中標示「跨市場共用」及其使用的方程式。
4. 顯示第 03 頁的預期移線方向（變數↑時各市場供給線／需求線）。
5. `k_Hy`、`k_Es`、`k_Gs` 預設為 0 時，y、s_E、s_G 旁顯示「已由成本／使用價值反映」。
6. 輸入驗證：`h > 0`；`epsilon ≥ 0`；`y、s_E、s_G ∈ [0,100]`；`u ≥ 1`；產能、預算、成本、價格類輸入 ≥ 0；r 可為負。違反時該欄顯示錯誤，求解暫停並保留最後有效圖表（標示為過期）。

### FR-2 係數面板（R02、R08）
1. 依市場分組列出截距 A、價格反應 b／d、因素係數 k，與外生因素分開。
2. 每個係數附單位（＝式中數量單位 ÷ 所乘項單位）與用途說明。
3. 提供「重設係數」（回到基準）；b、d ≤ 0 或 k < 0 時顯示「不符合第 04 頁符號慣例」警告，但仍允許計算（以便測試奇異等情境）。

### FR-3 方程式編輯器（R03、R08）
1. 主畫面預設折疊，使用者展開才編輯。
2. 每條式子可直接編輯文字；即時顯示由同一語法樹產生的公式預覽。
3. 單條「還原預設式」與「全部還原」。
4. 解析器只允許：數字、已宣告符號、`+ - * / ^`、括號、白名單函數（`abs sqrt exp ln log min max pow`）。不使用 JavaScript `eval`／`Function`。
5. 錯誤須指出位置（字元位置與符號）：未知符號、未知函數、語法錯誤、循環衍生式、除以零、非有限結果。錯誤時保留最後有效圖表並標示「非新均衡」。
6. 單位檢查：每條式子顯示「單位一致」「單位不一致（指出項目）」或「未驗證（原因）」三種狀態之一；不能完整檢查時必須明示未驗證。

### FR-4 求解（R04、R07）
1. **聯立模式（預設）**：未知數 P_H、P_C、P_A。
   - 先判斷模型對三價格是否為線性；線性時以線性代數直接求解（含尺度調整與部分樞紐），再代回六條式子核對。
   - 係數矩陣奇異時區分「無解」與「無唯一解」；病態時顯示「數值精度不足」。
   - 使用者改成非線性時使用數值求解（Newton 法＋回溯線搜尋）；找不到解就顯示狀態，不沿用上一情境的解作為結果。
2. **單市場模式（選用）**：選一個市場，其他兩個價格固定為使用者輸入或基準均衡值，只求該市場交點；介面清楚標示「其他市場價格固定」「條件均衡，非三市場整體均衡」。
3. **殘差檢查**：各市場相對殘差 `|S−D| / max(|S|,|D|)` 須小於容許值（預設 1e-9 線性、1e-8 非線性），依各自量級檢查。
4. **適用範圍**：價格、Q_H、Q_C、Q_A 或分群需求 Q_E_D、Q_U_D、Q_G_D 任一為負，標記「此情境不在模型適用範圍」，列出違反項目；不截斷、不改寫成 0。
5. 只有同時通過殘差與適用範圍檢查者才標示「有效均衡」。
6. 結果旁固定顯示「投入產出數量一致性尚未施加」說明。

### FR-5 圖表（R05、R09）
1. 三張圖：硬體、算力、AI 服務；縱軸價格、橫軸數量，軸標含實際單位。
2. 基準：淡色虛線供需曲線與基準均衡點；新情境：實線與新均衡點。
3. 基準曲線使用基準的因素與基準的其他市場均衡價格；新曲線使用新情境因素與新情境其他市場均衡價格。
4. 曲線由取樣本市場價格 P、計算 Q(P) 後以 (Q,P) 繪製；可只顯示非負區域，但不改寫公式或結果。
5. 標示價格與數量的絕對變化與百分比變化；基準值為 0 時百分比顯示「不適用」。
6. 滑鼠／觸控提示顯示 P、供給量、需求量；提供顯示範圍調整（價格上限、數量上限、自動）。
7. 圖旁顯示其他市場目前代入的價格（基準與新情境）。
8. 單市場模式只畫固定其他兩價的條件曲線，不標成整體均衡。

### FR-6 情境管理（R06）
1. 「儲存為基準」：把新情境複製成基準。
2. 「重設」：新情境回到基準；「還原網站預設」：回到示範情境。
3. 「複製情境」：以新名稱保存目前情境到本機情境清單，可載入、刪除。
4. 匯出／匯入 JSON：包含公式、因素、係數、單位、數值、來源標記、求解設定、基準與結果摘要。匯入後重新求解，若與檔案內結果不一致須提示。
5. 缺值（null、「待填」、非數字）匯入時報錯，不自動補 0。
6. 目前工作階段自動存入 `localStorage`；重新整理可恢復。不同瀏覽器／無痕視窗各自獨立，不改寫網站預設模型。

### FR-7 教學提示（R08）
1. 顯示第 03 頁的預期移線方向。
2. 另顯示「引擎實際局部移線」：固定跨市場價格，以數值差分計算因素↑時各式數量變化方向；與第 03 頁不一致時提示（例如使用者改式後）。
3. 完整均衡的變動方向只由求解結果呈現，不預先寫死。

### FR-8 示範情境（R08）
1. 提供一組可執行的假設示範情境；所有補入的因素值、係數、截距皆標示假設。r＝3.64（FRED SOFR 2026/09/09）、e＝0.0917（EIA 美國工業平均 2026/06）標示觀測值與出處。
2. 截距以「示範校準」反推：先選正價格與正數量的基準點，再令各式通過該點。介面與文件說明這不是市場估計。
3. 校準點必須由獨立的求解流程找回（測試驗證）。

## 8. 已知限制（須在介面與文件揭露）

1. 係數尚未實證估計；示範數值為假設。
2. 未施加投入產出數量一致性：算力需求近似式未強制 Q_C ＝ a×Q_A＋訓練耗用。未來若要加入，需重新整合算力需求與模型生產關係，不是硬加第四條方程式。
3. 比較靜態：Q_H 不自動加入 K_C；不模擬部署、退役與未來十年。
4. 利率同時進入三市場是簡化假設（投資與融資成本管道）。
